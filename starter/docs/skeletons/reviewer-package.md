*The branch diff, the branch's committed range from its base, `origin/main`, to HEAD; a seat reads the repository and runs its own checks, so the package points at the evidence and is not itself the evidence (process.md §II, stage 6; §Adversarial review protocol, Scopes; §Model policy, Rules for a seat call).*

## The plan

*The merged plan, by path (process.md §II, stage 6).*

## The ledger's rulings

*The ledger's path, which holds neither review's report until both return, and every ruling made during the loop, the orchestrator's own, counsel's and any marked provisional, each with its tier or trigger, for the reviewer to confirm, refine or overturn (the reviewer charter, Cover 4; process.md §II, stage 6; §Model policy, Records).*

## The gate's findings

*The final gate's findings, each with its severity and the orchestrator's proposed ruling and reason; a proposed dismissal stands only with the reviewer's explicit agreement (process.md §II, stage 6; the reviewer charter, Cover 4).*

## The deferred minors

*The minors the task reviews deferred to the reviewer, each by file and symbol, for it to mark fix before merge or can wait (the reviewer charter, Cover 5).*
