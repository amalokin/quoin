# Gate focus — ‹stage› gate on ‹item›

## Stage and scope

*The gate's stage (the design gate at stage 4, the final gate at stage 6, or a re-gate) and its committed scope, the base and HEAD, the base described in words, since the focus text carries no dash-led token (process.md §Adversarial review protocol, Scopes; The gate package).*

## Mandatory reads

*The design sections that govern the diff and the item's editable surface with its exceptions, each by path (process.md §Adversarial review protocol, The gate package).*

## Questions

*The questions that matter; for a document review, the questions the document must survive (process.md §Adversarial review protocol, The gate package; Document-review variant).*

## On a re-gate

*Only on a re-gate: the fix commit, the areas earlier rounds confirmed, and a request for a verdict (process.md §Adversarial review protocol, The gate package; The gate transitions).*

## What the review returns

*That the review states what it read or discloses the context it lacked, and the closing request the gate runbook gives (process.md §Adversarial review protocol, The gate package; `docs/runbooks/codex-gate.md`, the focus text).*
