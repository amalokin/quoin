# Explainers — index

*Basics-to-advanced explanations of the math and methods the project uses ([process.md](../process.md) §Doc taxonomy,
the Explainer row). The canonical form is Markdown with LaTeX math and figures as committed SVGs. A rendering, such as
a published page for comfortable reading, may be regenerated at milestones; the Markdown is always the source of
truth, and a rendering carries a provenance line naming the file and the commit it was rendered from. Each explainer
carries a currency line naming the rows that amended its math since it was written; its row's *Status* here says where
it stands against them.*

<!-- fill: the audience, who reads the explainers and what they can already do; the rule is that each explainer builds from there, gently enough to reconstruct a method from first principles -->

A new explainer gets a row in the PR that writes it, and the PR that amends the math an explainer teaches updates that
row's *Status*, so a reader can tell a current explainer from a stale one.
